# Mi carrito

Escanea los códigos de barras en el Carrefour y ve sumando lo que llevas gastado.
Incluye los precios de mis tickets (jul–nov 2026) para buscar productos por nombre.

- **Web instalable:** se publica sola en GitHub Pages (Ajustes → Pages → Source: GitHub Actions).
- **APK Android:** cada cambio genera `mi-carrito.apk` en *Releases*.

El código de la app está en `www/index.html`.
